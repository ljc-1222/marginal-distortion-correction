# Figure sources

The figures are composed from the image assets accompanying the Computational Photography final report, *An Interactive Annotation System for MaDCoW-Based Marginal Distortion Correction*, by 林進成 and 黃義凱.

All source panels are uniformly resized and placed on a neutral canvas with descriptive labels. Their aspect ratios and full panel extents are preserved. The local comparisons use the crops already included in the report assets. JPEG encoding is used for delivery; no additional geometric correction, retouching, or border removal is applied to the experiment images.

- **`correction-examples.jpg`** uses `360_view.png`, `360_result.png`, `pinhole_view.jpg`, and `pinhole_result.png` (report Fig. 4).
- **`local-constraints.jpg`** uses `360_wo_annotate.png`, `360_annotate.png`, `pinhole_wo_annotate.png`, and `pinhole_annotate.png` (report Fig. 6).
- **`constraint-study.jpg`** uses `number_original_view.png`, `number_stero.png`, `number_ROI.png`, and `number_line.png` (report Fig. 5). The source spelling `stero` is retained here to identify the original file.
- **`ulsd-candidates.jpg`** uses `ULSD.png` and `ULSD_result.png` (report Fig. 2). The panels illustrate the project's ULSD exploration; the detector is attributed in [results and analysis](../results.md#why-use-interactive-snapping).
- **`failure-cases.jpg`** uses `fail_case_2.png` and `fail_case_3.png` (report Fig. 7).

The report PDF, LaTeX source, model checkpoints, and working annotation outputs are not included in this documentation asset set.
